# PhD Research: The ACCESS framework - Using inertial sensors to understand and improve manual wheelchair navigation in cities

Roxana Ramirez Herrera’s doctoral project combined inertial sensing and co-design to describe the effort involved in wheelchair journeys and inform route planning and urban accessibility.
