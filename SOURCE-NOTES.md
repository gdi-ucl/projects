# Sources and coverage

Checked: **2 November 2026**.

Six pages of the [GDI project listing](https://www.disabilityinnovation.com/projects) were crawled, followed by project links discovered inside their detail pages. This produced **91 accessible profiles**: **43 main profiles** and **48 nested profiles**, including 19 video resources. These records overlap in subject and are not a count of distinct funded projects. Original source paths are retained so related records remain traceable.

Summaries are newly written from the source pages. Metadata is transcribed where available, and images are embedded from GDI’s image host with source credit. No full source pages, publication PDFs, software or datasets are copied into this repository. No licence to reuse third-party materials is implied.

Source statuses, dates and staff descriptions have not been independently reconfirmed. The import is a snapshot, not an automatic synchronisation. Future refreshes should preserve researcher edits and review source changes before committing.

## Scope and checks

All accessible source pages received a profile and source record. Internal Markdown links were checked locally. Resource links are retained from the website and may themselves be outdated or restricted; they were not exhaustively tested. Related programmes sometimes have both standalone and nested source pages, so both records are preserved.
