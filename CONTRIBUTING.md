# Add or update a project — no coding needed

1. Sign in using your own GitHub account. You need Write access to this repository to save changes directly.
2. [Find your project](PROJECTS.md) and open its folder.
3. To update the description, open **README.md**, click the pencil, and replace or add text. Add a link to the working repository if one exists.
4. To upload approved files, return to the project folder and choose **Add file → Upload files**. Drag in your files and write a short description of the change.
5. Choose **Commit changes**. If GitHub offers a pull request instead, submit it for a maintainer to review.
6. Share the URL of your project folder. Anyone can read this public collection without signing in.

For a new profile, use **Add file → Create new file**, enter `your-project-name/README.md`, and copy the content from [_template/README.md](_template/README.md). Add the new profile to PROJECTS.md.

## Choose the right place

- Public project introductions and approved resources can go here.
- Create a separate repository from [template-project](https://github.com/gdi-ucl/template-project) when a project needs its own visibility, collaborators or software workflow, then link it from the profile.
- Put publication records in [publications-and-reports](https://github.com/gdi-ucl/publications-and-reports) and link to them from the relevant project.

Check that you have permission to publish each file. Keep participant information, confidential material and restricted data in approved storage. Git history retains earlier versions of files.

## Maintain the record

Update `project.json` when changing source details or links, and record when you checked them. Status copied from an older website page should not be presented as newly confirmed. Keep source and image credits. This collection does not apply a blanket reuse licence to source material.
