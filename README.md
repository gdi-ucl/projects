## Add your work

Open a project folder, then edit its README or choose **Add file → Upload files**. See the [simple upload guide](CONTRIBUTING.md).

This is a public catalogue. All its folders share the same visibility. Use the [project template](https://github.com/gdi-ucl/template-project) for a separate project repository with its own access settings.
